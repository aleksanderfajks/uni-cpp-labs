# University C/C++ Labs

Labs exercises from my C/C++ course at Wrocław University of Science and Technology.

## Topics Covered
- Pointers and memory management
- Data structures and algorithms baisics
- File I/O
- State machine implementation in code
- Implementation and consolidation of programming libraries
- Basic code testing

## Structure
- lab01 - intro to C/C++
- lab02 - variable operations and control statements
- lab03 - standard input/output
- lab04 - functions and debugging
- lab05 - intro to pointers
- lab06 - file operations
- lab07 - references and dynamic memory allocation
- lab08 - memory layout and operations
- lab09 - algorithms and data structures
- lab10 - functional pointers
- lab11 - state machine
- lab12 - programming libraries implementation
- lab13 - software testing
